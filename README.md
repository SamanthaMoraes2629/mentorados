Sistema de Autenticação Django
Este projeto implementa um sistema de autenticação básico usando Django, com páginas de login e cadastro estilizadas com Tailwind CSS.

Funcionalidades
Cadastro de novos usuários

Login de usuários existentes

Validação de formulários

Mensagens de feedback para o usuário

Design responsivo e moderno

Tecnologias Utilizadas
Django (Python)

Tailwind CSS

HTML5

CSS3

Estrutura do Projeto
Copy
usuarios/
├── templates/
│   ├── cadastro.html - Página de cadastro de novos usuários
│   ├── login.html - Página de login para usuários existentes
│   └── base.html - Template base para as páginas
Como Executar
Clone o repositório

Instale as dependências (Django)

Execute as migrações

Inicie o servidor de desenvolvimento

Requisitos
Python 3.x

Django

Navegador moderno
